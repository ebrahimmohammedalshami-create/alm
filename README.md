# alm

## نظام مكافحة غسل الأموال ومراقبة الاحتيال المالي (Tahseel AML & EFRM Compliance)
### منصة تحصيل الإلكترونية | شركة الترا سوفت للحلول المالية (Ultimate Pay Solutions)

مشروع الربط والتكامل الشامل بين منصة تحصيل (Tahseel) ومنظومة مكافحة غسل الأموال ومراقبة الاحتيال اللحظية EFRM (منصة RiskBrains / FinFactory).

---

### 🌟 الميزات والمواصفات المعتمدة:
1. **فحص المنشآت والشركاء (KYB & Sanctions Screening):**
   - فحص آلي للكيان الأساسي (`ORGANIZATION / CUSTOMER`) وكافة الشركاء والمفوضين والملاك (`INDIVIDUAL`).
   - ربط الأطراف التابعة بالكيان الأساسي عبر `primary_entity_id`.
   - فحص الوسائط السلبية (`Adverse Media Check - AMC`) وقوائم الحظر الدولية ومجلس الأمن و OFAC والبنك المركزي اليمني.
   - احتساب المستفيد الحقيقي النهائي تلقائياً (`UBO` لأي حصة تبلغ 25% فما فوق).

2. **مراقبة المعاملات المالية اللحظية (EFRM Transaction Monitoring):**
   - النمط المتزامن (`SYNC`): ردع فوري لحركات الاحتيال في نقاط البيع (`POS`) وبوابة التجارة الإلكترونية (`ECOM`) خلال أجزاء من الثانية.
   - النمط غير المتزامن (`ASYNC`): للتدقيق والمراقبة والتسويات الختامية.
   - دعم حركات البطاقات (`card_txn`) ومطابقة معايير ISO 8583.
   - العملات المدعومة: `886` (ريال يمني), `840` (دولار أمريكي), `682` (ريال سعودي).

3. **منظومة الـ Webhooks وإغلاق القضايا الرقابية:**
   - استقبال أحداث اتخاذ القرار غير المتزامن (`TRANSACTION_DECISION`).
   - استقبال تحديثات إغلاق القضايا الرقابية (`CASE_ACTION_UPDATE`).
   - تجميد سجلات التدقيق لمنع التعديل أو الحذف (`Immutable Audit Trail`) لمدة 10 سنوات امتثالاً للقوانين المصرفية.

4. **معمارية نمط المحول (Adapter Architecture & SOLID):**
   - عدم إجراء أي تغيير أو تعديل على جداول أو حقول قاعدة بيانات تحصيل الأصلية.
   - الترجمة والتطبيع التلقائي للبيانات إلى الصيغ القياسية المطلوبة لمزود الخدمة.
